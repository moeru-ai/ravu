# RAVU

When I ([@kwaa](https://github.com/kwaa)) first discovered [ClawdBot](https://github.com/openclaw/openclaw), I wanted to build a personal agent of my own. The idea stayed with me. Now, it's finally time to begin.

RAVU carries forward the cognitive science approach of [Plast Mem](https://github.com/moeru-ai/plast-mem), with a more personal direction in mind. Something closer to you, shaped by the time you spend together.

Perhaps “personal agent” isn't quite the right name for it. I think of it more as a personal waifu: someone to share the little moments with, and, when you want, someone who can help you get things done.

There's still a long way to go. But every meeting has to start somewhere.
